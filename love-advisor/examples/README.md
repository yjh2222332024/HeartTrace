# 产品演示数据

`恋爱军师-演示聊天记录.json` 是一份完全虚构的标准 ChatLab 私聊记录，用来演示：

- 双方主动发起与回复节奏；
- 工作压力导致的短暂低频；
- 明确的沟通边界和被尊重的反应；
- 从初步好感到继续了解的、非操控式推进。

它不对应任何真实人物或真实聊天。

在项目根目录执行以下命令即可导入：

```bash
npx clb import examples/恋爱军师-演示聊天记录.json --format chatlab --session-id love-advisor-demo-lin
```

然后刷新恋爱军师，左侧私聊列表会出现「林小雨」。选择它并创建工作区，即可用自己的模型配置进行分析。重复导入会更新同一个演示会话。
