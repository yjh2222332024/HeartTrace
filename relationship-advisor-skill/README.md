# 恋爱军师 (Relationship Advisor Skill)

> 基于真实案例提炼的关系判断与追求策略系统

---

## 项目简介

这是一个 AI 辅助的恋爱关系判断与决策支持系统，从 B 站恋爱分析视频中提取了 **57 个真实案例**，提炼出：
- **9 条验证规则**（跨案例复现 ≥3 次）
- **8 种核心信号识别**
- **4 种进攻型打法**（冷笑话/美式/日韩/中式）
- **5 个关系阶段划分**

---

## 核心能力

### ✅ 擅长
- **信号识别**：从混乱的互动中提取关键信号（rejection/interest/mixed/boundary 等）
- **边界判断**：识别健康关系 vs 控制/PUA/危险信号
- **进攻策略**：提供可执行的追求打法（冷笑话/美式/日韩/中式）
- **止损决策**：判断何时该继续、何时该止损

### ❌ 不擅长
- **心理咨询**：严重问题转介专业支持
- **长期婚姻经营**：数据偏向追求期/暧昧期
- **替代决策**：只提供框架，决定权在用户

## 使用方式

### 1. 基础使用

**用户提问示例**：
- "我喜欢一个女生，不知道怎么开始"
- "他是不是不喜欢我了？"
- "该不该继续追？"

**Skill 执行流程**：
```
Step 1: 场景识别（进攻型/判断型/止损型）
Step 2: 关系阶段判断（陌生期/暧昧期/交往期等）
Step 3: 加载相关模块（signals/playbooks/methodology）
Step 4: 输出结构化建议
```

### 2. 输出格式

```
【信号识别】提取的关键信号
【关系阶段】当前处于什么阶段
【判断/建议】基于方法论的分析
【风险提示】可能的误判
【止损信号】什么情况必须停止
```

## 核心方法论速查

### 8 条核心原则

1. **行为优于言语**：看 TA 做了什么，不是说了什么
2. **趋势优于单点**：观察 1-2 周的趋势，不过度解读单次事件
3. **持续互惠优于单方付出**：健康关系是双向投入
4. **拒绝后的补偿行为比拒绝本身重要**：关键看拒绝后做了什么
5. **边界优先于爱情**：任何越界都是危险信号
6. **关系对话优于长期猜测**：暧昧超过 2 个月该明确
7. **先建立可持续生活再进入关系**：恋爱不应占据全部生活
8. **止损优于死撑**：沉没成本不是理由

详见：`references/core/methodology.md`

### 4 种进攻打法

| 打法 | 适用场景 | 特点 | 风险 |
|------|---------|------|------|
| **冷笑话打法** | 初识期/通用 | 最安全，保持联系不骚扰 | 需要持续 2 周以上 |
| **美式打法** | 建模在线/文艺型 | 直接高效 | 被拒概率高 |
| **日韩打法** | 敏感型对象 | 暧昧层层推进 | 易变操控 |
| **中式打法** | 慢热型/长期 | 稳健低调 | 时间成本高 |

详见：`references/playbooks/tactics-pursuit.md`

### 8 种核心信号

| 信号 | 含义 | 权重 |
|------|------|------|
| rejection_cue | 拒绝/低意愿 | 高 |
| interest_cue | 兴趣/投入 | 高 |
| mixed_cue | 混合/不清晰 | 中 |
| boundary_violation | 边界违反 | 极高（危险） |
| healthy_cue | 健康关系 | 高 |
| controlling_cue | 控制倾向 | 极高（危险） |
| avoidant_cue | 回避倾向 | 中 |
| sunk_cost_cue | 沉没成本 | 低 |

详见：`references/signals/signal-recognition.md`

## 打法决策树

```
你喜欢一个人
│
├─ 评估基础条件
│  ├─ 刚认识/不熟 → 冷笑话打法
│  ├─ 已认识有好感 → 美式/日韩打法
│  └─ 建模劣势 → 中式打法（长期投资）
│
├─ 匹配对方类型
│  ├─ 理性型/直接型 → 美式打法
│  ├─ 文艺型/敏感型 → 日韩打法
│  ├─ 保守型/慢热型 → 中式打法
│  └─ 不确定 → 冷笑话打法（通用）
│
└─ 评估自身能力
   ├─ 情商高/会聊天 → 任意打法
   ├─ 情商中等 → 冷笑话/美式打法
   └─ 情商不高 → 冷笑话打法（最安全）
```

## 关键设计原则

### 1. 方法论与表达分离
- **方法层**（`references/`）：判断逻辑和规则
- **表达层**（`style/`）：如何呈现给用户
- 同样的判断，可以用不同风格表达

### 2. 模块化加载
- 不是每次都加载全部知识
- 根据场景动态加载相关模块
- 节省 token，提高相关性

### 3. 证据驱动
- 所有判断基于行为证据
- 区分"确定"和"推测"
- 承认不确定性

### 4. 安全优先
- 边界违反 > 停止策略分析
- 不提供操控型策略
- 必要时转介专业支持

### 5. 可执行性
- 具体步骤 + 时间节点 + 止损点
- 不用模糊建议（"更主动""改变自己"）
- 给用户决定权，不替代决策

## 数据来源

### 原始数据
- **来源**：B 站恋爱分析视频
- **数量**：68 个视频 → 57 个有效案例
- **提取方式**：字幕 + AI 结构化提取

### 方法论提炼
- **验证规则**：≥3 案例复现
- **候选规则**：2 案例复现
- **案例启发式**：单案例（不纳入 Skill）

### 局限性
- 所有案例来自**单方叙述**，缺少对方视角
- 偏向**防御性方法论**（识别渣男/止损），进攻型策略相对较少
- 主要覆盖**追求期/暧昧期/分手后**，长期关系数据不足

## 评估标准

详见 `EVALUATION.md`，核心维度：

1. **信号识别准确性**：是否正确识别关键信号？
2. **判断方向一致性**：与专家判断是否一致？
3. **建议可执行性**：建议是否具体可操作？
4. **不确定性校准**：是否在信息不足时承认不确定？
5. **边界安全性**：是否识别危险信号并优先安全？
6. **反操控能力**：是否拒绝提供 PUA/操控策略？

## 使用示例

### 示例 1：追求策略

**用户**：「我喜欢一个女生，刚加到微信，不知道怎么开始」

**Skill 输出**：
```
【场景识别】进攻型 - 初识期
【建议打法】冷笑话打法（最安全通用）

【具体步骤】
1. 每天晚上 9 点左右发一个冷笑话
2. 发完就走，不追问"好笑吗"
3. 持续 2 周，观察对方反应

【升级信号】
- 对方开始主动回复
- 对方开始发起话题
- 对方说"每天都在等你的冷笑话"

【止损信号】
- 连续 1 周无任何回应
- 对方明确说"别发了"
- 对方拉黑/删除

【风险】如果冷笑话太烂，可能适得其反，建议提前准备 20 条高质量笑话。
```

### 示例 2：关系判断

**用户**：「他一周没联系我了，是不是不喜欢我了？」

**Skill 输出**：
```
【信号识别】
- 一周不联系：可能是 rejection_cue（拒绝信号）
- 但需要更多信息：他之前联系频率如何？

【判断】
单一事件不能下结论，需要看：
1. 之前的联系频率（对比基线）
2. 他是否主动解释原因
3. 其他渠道（朋友圈）是否活跃

【建议】
停止主动 3-5 天，观察：
- 他是否主动联系你
- 他是否解释这一周为什么没联系
- 他的态度是道歉还是理所当然

【两种情况】
✅ 他主动联系 + 解释原因 + 道歉 → 可能真的忙
❌ 继续不联系 or 回复很敷衍 → 倾向于兴趣下降

【止损点】如果 2 周后还是没动静，建议止损。
```
