# 拒绝与朋友区

> **为什么不用 per-case JSON**：上一轮 per-case 提取对这些案例只产出模板化字段。
> 本文件纵向通读原文，每条规则带 `BV:行号` 溯源。

**用法**：用户描述「被拒绝了」「在朋友区/备胎」「一直单方面付出」「要不要继续追」时加载。
本主题与 B9（明确拒绝后推进即越界）、P2（fold）、P16（撤退期准则）配套：

## 主体规则

## FZ1 · 止损的落点：停止低质量付出，转向自我提升 【B 级】

**判断式**：如果对某人持续单方面付出而对方无对等回应（不回、不推进、只接受不给予），
在确认非双向信号后，更支持停止该付出并把资源转向自我提升，而不是加大投入或换花样继续。

**机制**：单向付出不产生吸引力，只消耗自己并降低自身在对方眼中的价值；
吸引力只能来自自身价值的实质变化。

**证据**（2 篇复现，措辞不同结构相同）
- `BV11wEQzmEKJ:231-244`「我每天坚持给我喜欢女神点那个QQ主页赞……天天给点赞 主页是能
  长出花来还是长出树来 搁那当浇水呢 你有那功夫 你自己好好的锻炼一下身体啊 练一下体型……
  你得提升自己嘛」
- `BV11wEQzmEKJ:700-716`「男生关注自己 关注自我的提升 让自己变成一个价值更高的人……
  你问我还有机会吗 啊就你这个心态 你要不转变的话 你一辈子也没机会啊」
- `BV1qyFjz4EjL:647-651`「我跟你说的冷笑话打法 这都是这就是常规打法 你文艺女
  我觉得你退避三舍吧」＋`755-762`「你要真喜欢文艺女这些东西 你真得学……这得花点功夫」
  （四个月无进展 → 停旧打法＋补实质，结构相同）

**失效条件**：对方仍存在互动增量（主动找你、回抛话题、接受并回应邀约）时，减少付出不是
止损，应按 P2 判跟注；止损的**方式**同时受 P16 约束（不发长文、不用重词、不自我贬低）。
**另见**：B9、P2、P16、FZ7。

## C 级留档观察（不进主体，验证后可升级）

- **FZ2 · 明确拒绝的行为信号清单（B9 的信号细化）**：直接说「不喜欢你这样的」、主动解释
  「不联系是怕你误会我在吊你」、退还你写的信、发出「再 X 就注销/拉黑」式通牒、删除好友
  （红色感叹号）、长期只回敷衍消息——且无反向互动增量 → 判定明确拒绝，而不是害羞或犹豫。
  证据：`BV11wEQzmEKJ:350-360`「他说不喜欢我这样的……我觉得这个女生其实是一个很有素质的
  女生了 就是他还跟你说 不想跟你说太多话 怕你觉得她吊着她」；`258-259`「我要是再点赞她就注销」；
  `327-330`「把我之前写的信又送了回去 我都没想到他还留着」；`BV1BzqKB6EdF:473-476`「结果上车后
  点开Z的微信 换来的是红色感叹号」。
  机制：拒绝的明确性由「对方主动消除模糊」的动作决定（与 B9 同构）。
  注：主播将「主动解释怕吊着你」评价为**有素质**——对方没义务给理由，给了理由是恩惠不是台阶。
  升级条件：主播直接表述再复现 1 篇即升 B。
- **FZ3 · 「不反感」≠「有兴趣」（假性积极信号）**：不骂、不删、给表情包，但持续无互动增量
  与推进 → 判定「不跟注」而不是「有意思」。证据：`BV1qyFjz4EjL:613-619`「我连续发了四个月
  冷笑她没有骂我这种哇 很有趣 还有表情包……不过聊完就不知道聊什么」；`BV11wEQzmEKJ:321-322`；
  `BV1BzqKB6EdF:452-457`「打了一晚上电话 他睡着 我也没有挂断……第二天他就不怎么理我」。
  机制：无摩擦是成本最低的默认状态，不构成投入；兴趣的可检验指标是**对方主动投入**。
  与 P2「不跟注=fold」同构。
- **FZ4 · 情绪供给型「朋友区」：需求投射，不是亲密**：留在关系里的核心动机是填补自己的
  空虚/安全感缺口（对方更像「心理辅导师」）→ 判定需求投射型关系（伪亲密）。
  证据：`BV112ieYKEYM:53-57`「我们的相处方式更像心理辅导和患者的关系」；
  `165-183`「因为你自己的人格现在是一个缺陷的状态 你需要有一个人来填补这一块额 但这是不好的啊……
  爱本身它是一种选择 它不是一种诉求啊」；正面表述 `184-191`「爱就是你自己的内心已经非常的夯实了……
  很多能量你已经溢出去了」。
  失效条件：双方人格稳定、互相提供情绪价值且有对等回流的关系不适用（本卡判**单向索取动机**）。
- **FZ5 · 明确拒绝后可停留在朋友位置，前提是停止追求动作**：证据 `BV11wEQzmEKJ:381-389`
  「不喜欢你已经表现的很明确了 但你还要这样子……自我提升一下 当朋友可以」。
  机制：拒绝否定的是恋爱关系而非社交关系；继续追求动作会把残余的社交信任也消耗掉。
  失效条件：对方已删除/拉黑切断关系（`BV1BzqKB6EdF:473-476`）时不存在朋友位置选项。
  注：4 篇中**没有任何「朋友区突围成功」的正例**。
- **FZ6 · 纠缠/错位付出的社交反噬**：共同社交圈可观测时，纠缠 → 预期「圈层内名声受损＋
  被公开羞辱＋关系进一步恶化」，而不是「坚持能感动对方」。证据：`BV1BzqKB6EdF:268-274`
  「我发了朋友圈 Z知道了 给我骂了一顿……感觉引发圈子里挺大的轰动」；`291-293`「后来我缠着他
  他朋友还加我微信来骂我」；`BV11wEQzmEKJ:176-178`「她闺蜜和现任来找我送了信 内容就是骂我舔狗」。
  失效条件：无共同社交圈的纯二人关系不适用「圈层」部分。
- **FZ7 · 单恋真实性自查：「双向列表法」**：自认深爱却列不出对方**三条以上具体吸引点**、
  同时答不出「她凭什么喜欢你」→ 判定第二性征冲动＋形象投射而非爱情；先自我提升。
  证据：`BV11wEQzmEKJ:489-537`「你拿一个表列出来 你喜欢她什么 实际上大部分人最多最多能举出
  三条……你只是一种非常天然的第二性征发育以后带来的一种冲动……你暂时还不懂什么叫做爱」；
  `541-569`「那你先列个表 人家凭什么喜欢你 你列一下吧……你就知道至少知道自己在哪里该提升了嘛」。
  失效条件：长期深度相处（同事/多年好友）后产生的感情，「三条」启发式不适用。
  结构与 P1「见色起意」、P2「手里牌」同构，建议同步回填 advancement。
- **FZ8 · 朋友区突围的可行性门槛**：仅当同时满足「①未被明确拒绝 ②打法与对象类型匹配
  ③有可新增的自身价值」才支持尝试；任一缺失更支持维持普通朋友（FZ5）或撤退（P2 fold）。
  证据：`BV1qyFjz4EjL:625-651`「我给你说的这套流程是让你找普通人的 你上来找文艺女啊……
  你没那个金刚钻 你不要揽那个瓷器活了」（条件②缺失→退避）；`BV11wEQzmEKJ:381-389`
  （条件①缺失→只剩朋友位）。
  风险：误用本卡会变成「再试一次」的心理许可；主播从未给出突围成功率承诺，
  最接近的是反向条件句 `BV11wEQzmEKJ:712-713`「你要不转变的话 你一辈子也没机会啊」。
