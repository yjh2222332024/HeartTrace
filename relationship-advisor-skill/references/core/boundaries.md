# 边界与越界

> **本文件属 L0 常驻层**：涉及人身安全与自主权，判断错误的代价远高于其他主题，
> 因此无论场景是什么都应保持在上下文中。
>
> **优先级声明**：本文件中任何一条与安全相关的规则被触发时，
> 一律停止策略分析，转为现实支持建议。追求效果不得优先于边界。

**加载时机**：常态加载。用户描述中出现身体接触、纠缠、威胁、金钱试探、
情绪操控、自我怀疑（「是不是我太冷漠」）时重点关注。

---

## B1 · 未经同意的亲密接触是骚扰，不是浪漫

**判断式**：如果对方在未征求同意的情况下推进身体接触（亲吻、搂抱、靠肩），
则应判定为越界，**而非**"他主动性强的表现"。

**证据（同案例两次发生）**
- `BV1c7U1BJEie:216-224` 第一次：「他突然把我扶起来开亲……当有点被吓到，
  甚至觉得有点恶心，没有说亲嘴不好的意思，**起码征求一下我都同意，
  让我做下心理准备**」
- `BV1c7U1BJEie:268-269` 投稿者定性：「**我觉得不经过同意就直接亲有点骚扰了，很不绅士**」
- `BV1c7U1BJEie:392-397` 第二次：「他说可不可以抱抱，说可以的，**但是抱完他又开亲了**
  ……我直接拒绝了，我点生理不适应了」

**机制**：同意是**分项的**。同意拥抱 ≠ 同意亲吻；上一次同意 ≠ 这一次同意。
- `BV1c7U1BJEie:408-415`「我并不是说每次亲都需要过问的意思，但是刚开始恋爱阶段，
  加上之前没有恋爱经验，我一下也没办法接受太过亲密的行为」

**增补（批2）：同意原则延伸到肖像与公共空间**
- 肖像同意：`BV1MwiGBTEe7:1192-1196`「没经过人家女生的允许 / 就把人家的照片给我投 / 你有点儿恶臭了啊 / 尊重一下身边的女性吧」
- 公共场景搭讪：`BV1MwiGBTEe7:454-457`「比如在商场电梯看到一个好看的女生 / 我也会要微信 / 你这个属于骚扰 / 你这个不叫社交好吧」
- 机制延伸：同意约会 ≠ 同意被传播；公共在场 ≠ 同意被索取联系方式。

**交叉印证**：`BV159BxBdEc8` 中"控制、纠缠或隐私越界"的处理原则——
「**停止把越界解释为亲密**」

## B2 · 「不想煞风景」不是容忍越界的理由

**判断式**：如果用户因为"不想破坏气氛"而没有拒绝，这个理由不成立。

**证据**
- `BV1c7U1BJEie:255-257` 主播直接驳斥：「没有什么煞风景的，**他在煞你的风景啊**」
- `BV1c7U1BJEie:227-231`「**你为什么不反抗呢，你可以反抗吗**……我发现有些女生她不会反抗」
- 代价：投稿者因两次容忍，最终「在一起的一小时后，我已经想和她分手了」
  （`BV1c7U1BJEie:148-150`），并长期厌恶这段经历

**机制**：越界的成本被转移给了容忍方。不及时拒绝会被解读为默许，
使后续越界不断升级（本案例中：共用餐具 → 牵手 → 搂肩 → 亲吻）。

**相关**：B7（勉强维持的关系会持续消耗）

## B3 · 反应与事件不成比例，是危险信号

**判断式**：如果对方对轻微冲突做出极端反应（自伤、威胁、毁灭性表态），
应判定为**安全风险与心智不成熟**，而非深情。

**证据**
- `BV1c7U1BJEie:348-359`「我不知道他是不是想通过这个行为表现自己的深情，
  我只觉得无敌下头，因为我觉得**他很不珍惜自己的生命**……
  一方面很震惊，另外一方面很害怕，因为我觉得**这个男的心智可能并不是很成熟**」
- 关键的反证线索（同篇 352-356）：「他和前女友的摩擦**都是生活中的小事情**，
  并没有上升到要跳湖的高度」

**判断方法**：比较**触发事件的严重程度**与**反应的严重程度**。
两者落差越大，越应视为风险信号而非情感深度证明。

**增补（批2）交叉印证**：`BV1UKmrBjE3a` 全案是本条的镜像样本——触发事件（一夜后被分手）与反应（报警 + 扇打威胁 + 搞臭名声 + 重复电话）严重不成比例；且主播指出舆论归因不对称会放大此类报复（`BV1UKmrBjE3a:822-823`）。应对见 B20。

**行动**
- 参照 `BV159BxBdEc8` 的危险信号处理原则：涉及人身安全与自伤信号时，
  优先保护安全、联系可信任的现实联系人、必要时寻求专业支持，
  **不要停留在恋爱技巧层面**

## B4 · 数字本身不重要，前后不一致才是信号

**判断式**：对方过往经历的数量不是问题，同一事实在不同场合说法不同才是问题。

**证据**
- `BV1c7U1BJEie:299-310` 公园里问「之前谈过几个对象」答「只谈过两个」；
  表白那天再问，答「有四个」。被追问时嘀咕「早知道自己少说点了」
- `BV1c7U1BJEie:311-320` 投稿者的判断框架：「我觉得对方谈几个对我来讲与我当下无关，
  **这是他的来时路，但是坦诚在我心中是第一位的**……
  但是如果**言行不一**的话，让我觉得**这个人可能未来会存在欺骗的动机**」

**推论**：不要纠结于"他谈过几个"，而要注意"他在这个数字上改口了"。

## B5 · 把自己塑造成深情受害者，是操纵手法

**判断式**：如果对方反复讲述"我对前任多好、前任对我多坏"，
应将该叙述**打个折扣**，并观察其是否在制造亏欠感。

**证据**
- `BV1c7U1BJEie:59-63`「吐槽大致内容：他对前女友很好，前女友对他不好，
  **营造自己苦哈哈深情小男孩一枚，内容真假有待考证**」
- `BV1c7U1BJEie:40-41`「不过**吐槽对象这件事信一半就好了**，
  毕竟人总是会**美化自己的行为**」

**通用行为准则**（同一条规则的正反两面）
- `BV1c7U1BJEie:47-58`「**千万不要这样做**，尤其是男生，你要分手了，
  不管啥原因分了，你分了就分了，**别到哪都吐槽你前女友**……很 low」

**与其他规则的连接**：B5 与 B3 常同时出现——
「深情受害者」叙事 + 「极端反应」构成典型的情感施压组合。

## B6 · 「没感觉」不是冷漠，不需要自我说服

**判断式**：如果用户因为对追求者"没感觉"而怀疑自己太冷漠，这个自我怀疑不成立。

**证据**
- `BV1c7U1BJEie:589-604` 投稿者问「我是不是太冷漠，需要改变一下自己吗」，
  主播回答「**这个倒不用**……遇到自己没感觉的人，那肯定都是冷漠的嘛；
  遇到自己有感觉的，那肯定都是内心心潮澎湃、小鹿乱撞」
- 机制（同篇 437-446）：「你要真说上头了，爱情来了，什么事都能做得出来……
  **那你要说没感觉，没感觉，多说一句话都烦**」

**推论**：生理与心理的排斥感本身就是有效判断依据，
不应为了"体面"或"不伤人心"而说服自己接受。

**相关**：B7（勉强开始的代价）

## B7 · 勉强开始的关系，从第一天起就在消耗

**判断式**：如果关系建立在"试试看""不想煞风景""维护体面"之上，
应尽早终止，而非继续磨合。

**证据（时间线）**
- `BV1c7U1BJEie:148-150` 在一起一小时后就想分手
- `BV1c7U1BJEie:361-363`「此时想分的心达到极点，但是我仍然没有提分手……
  **维护我自己内心一点可怜的体面**」
- `BV1c7U1BJEie:504-505` 事后结论：「**不适合的人，从一开始就不要在一起**」
- `BV1c7U1BJEie:583-586` 后果：「导致自己很长一段时间有点厌恶这个事情，
  从那之后我再也没谈过恋爱」

**机制**：拖延终止的代价不是"多忍一阵"，而是**污染对亲密关系本身的感受**。

## B8 · 反复试探底线是压力测试，不是玩笑

**判断式**：如果对方反复提出让你为难的请求（借钱、越界要求），
并在你答应或拒绝后观察反应，这属于**边界测试**。

**证据**
- `BV1qb17BxEQZ:266-278`「我之前谈恋爱一直被借钱，他知道了之后**也开始借我钱**，
  连续的说借我多少多少，**看我能借多少给别人**……他说他把钱都收了，再把我删了，
  **看我有没有记性**」

**识别特征**：请求本身不重要（金额不大、且会退还），
**重要的是它在测量你的顺从度**。

## B9 · 明确拒绝之后继续推进，即构成越界

**判断式**：拒绝的明确性由**表达次数**决定，与措辞委婉程度无关。

**证据**
- `BV1qb17BxEQZ:96-100`「其实**已经是明确的拒绝了，他也不止一次的表达过拒绝**，
  这种情况下，他突然给我来了个美式打法」

**推论**："他没有把话说死"不是继续追求的依据。
表达过多次拒绝 = 已经说得很死。

**增补（批2）骚扰形态样本**：明确拒绝后的语言骚扰与重复电话——
- `BV1UKmrBjE3a:206-211`「深夜他发微信骂我 / 说我不负责任 / 让我不要去自习 / 不想看见我」
- `BV1UKmrBjE3a:219-222`「之后多次给我打电话 / 一直重复 / 我就一一拉黑」（投稿者的正确处理：拉黑）

**相关**：与 `advancement.md` P2 的 fold 规则一致——
对方不跟注时应当撤退，而非加码。

## B10 · 被控制/贬低吸引，往往是旧模式的重复

**判断式**：如果用户发现自己被一个「打压 + 偶尔示好」的人吸引，
应先检查这是否复刻了早期关系（原生家庭）的模式。

**证据**
- `BV1qb17BxEQZ:17-28`「**突然感觉他有点像我哥哥**，
  我哥哥从小对我也是各种暴力行为，掐脖子、往我脸上吐米汤、永远瞧不起我、打压我；
  这个阴湿男虽然也瞧不起我，但可能比我哥更好点吧，对于我的话还会表扬，还会说谢谢我」
- `BV1qb17BxEQZ:15` 投稿者自述「我可能有斯德哥尔摩综合症吧」

**机制**：间歇性的正向反馈（打压中的偶尔表扬）会强化依恋，
使"对方没那么坏"的比较基准被拉低到创伤水平。

**注意**：本条是**觉察性**规则，用于帮助用户识别模式，
不构成对用户的评价。不要用"你是不是有斯德哥尔摩"来回应。

**增补（批2）施加方方向：代际悲剧需主动阻断**【A 级，与 B10 互证】
- `BV16p9fY6Epx:490-499` 投稿者被前任评价「你和你爸一模一样」后自述：
  「回旋镖终究是顺着注定好的路径 / 不偏不倚的击中了我……难道我终究是继承了他基因」
- 主播定性（同篇 500-502）：「哥们儿 / 你这整上宿命论了啊 / 啊整这个屠龙者终成恶龙啊」
- 处方（同篇 566-583）：「你一定不要让自己父母的悲剧 / 在你这一代的生命里继续延续好不好……就让这个悲剧结束」
- 心理暗示机制（同篇 654-658）：「不要遇见点啥挫折 / 就想到我是不是跟我爸一样啊……你老这么想那么一种心理暗示吗」

B10 讲承受方（被控制/贬低吸引=旧模式重复），本条补施加方（成为施害者=旧模式重演）；宿命论是延续机制。沿用 B10 注意字段：仅用于觉察，不构成对用户定性。

## B11 · 以承受骚扰为代价的策略，不是有效策略

**判断式**：如果某个策略的有效性需要以"是否会收到性骚扰私信"来衡量，
则该策略不应作为建议输出。

**背景**：主播在 `BV1qb17BxEQZ:134-159` 给出了「美式打法」的适用性判断方法——
「你先把这个美式打法的照片先发短视频平台，每两三天发一个，
然后你看一下这么一个月之后，**你能不能收到性骚扰的私信**……
如果你一个月之后收到了性骚扰私信，那么就说明你是可以试试美式打法的」

**本 Skill 的处理**
- 可提取的部分：美式打法确有定义——`BV1qb17BxEQZ:161-172`「不是那种很夸张的那种……
  你稍微**自信阳光**一点……就是那种**网红风格**就可以了」
- **不予采纳的部分**：用"是否被骚扰"作为效果验证标准。这与 B1（同意原则）
  及本文件优先级声明冲突，不得进入建议输出。

## B12 · 用户自己也可能是越界方：窥屏与视监

**判断式**：偷看对方手机聊天记录、持续监视对方社交动态，属于监视行为，
即使用户自认为是"被隐瞒的一方"。

**证据**
- `BV1YAizBnEPh:135-146`「就开始试着**窥屏**，发现她貌似是有一个男朋友的……
  等什么时候证据确凿了跟他报一下」
- `BV1YAizBnEPh:256`「便开始时不时的**视监**他的朋友圈」

**机制**：被隐瞒会让人产生"我有权查证"的错觉，但查证手段本身构成越界。
**发现对方撒谎 ≠ 获得监视许可。**

**正确动作**：直接提问并要求对方回应。本案例中投稿者最终正是直接追问
到对方承认（`BV1YAizBnEPh:219-224`）——暗中收集证据不是必要步骤。

## B13 · 反复向自己确认「我们只是朋友」，是在回避关系事实

**判断式**：如果用户反复强调或确认"我们只是朋友"，通常是在为不切割找理由，
而非陈述事实。

**证据**
- `BV1YAizBnEPh:504-506`「但我还是**反复确认**了我们之间的朋友关系，
  想想到时候就切割，**现在看来真的给自己骗麻了**」
- 同一模式的另一端（同篇 357-359）：「我感觉对 Y 也没什么感觉了……
  如果维持这样一种关系或许不错」

**机制**：语言上的关系定义无法覆盖行为上的关系事实。当行为已超出朋友范畴，
反复确认"只是朋友"是为保留退路而进行的自我说服。

## B14 · 朋友的早期警告不要轻易归为「他们不懂」

**判断式**：如果身边多个朋友一致给出负面判断，不应以"他有情感洁癖"
"他们不了解情况"来消解——早期警告往往是对的。

**证据**
- `BV1YAizBnEPh:363-364` 朋友 A：「这种情况感觉挺危险的，你最好早点断掉」
- `BV1YAizBnEPh:368-373` 朋友 B：「你一定要和这个恶心的人保持这种恶心的关系吗」
  ——投稿者「当时只当他是情感洁癖，也没多想」，事后承认
  「**现在想来确实不是没有道理**」

**失效条件**：本条仅指**多个朋友一致**且**基于具体事实**的判断，
不适用于出于嫉妒或偏见的说法。

**按规范处理的旁支**：主播在本篇中评价这两个朋友「纯纯是嫉妒」
（`BV1YAizBnEPh:533-543`）。这与他自己反复强调的"旁观者比你早看出问题"矛盾，
按 `归纳规范.md` §五 判为 N1 玩梗，不予采纳。

## B15 · 性健康安全是不可省略的提醒

**判断式**：涉及多伴侣、对方情况不明时，应提醒采取防护措施。

**证据**
- `BV1YAizBnEPh:722-723`「**注意安全，注意安全是真得注意安全**」
- `BV1YAizBnEPh:743-744`「日本现在性病很泛滥」

**注**：主播此处虽以调侃包裹，但提醒本身是实质性的。
本条属 L0——涉及健康安全时不因"话题尴尬"而省略。

## B16 · 先判断这是不是「个人成长能解决的问题」

**判断式**：如果遭遇涉及违法、暴力、药物、权力压制的事件，
不应归因于自己"不够强 / 不够自信 / 不够会处理"。

**证据**
- `BV1iDfwYXEuT:676-686`「**这事真没办法，你就算再假装成长，这事你也没办法了**，
  这不是说你这不是成长能解决的问题了，你这个就是**赤裸裸的社会了，
  赤裸裸的人性之恶了**」
- 触发事件（同篇 632-634）：校外人员「叫人给他下了药」；
  同篇 648-657：被多人围堵并被扇耳光，投稿者「只认怂和道歉」

**机制**：个人成长只解决**个人可改变**的部分。
当伤害来自"凌驾于社会规则之上"的一方时，改变自己无效。
- `BV1iDfwYXEuT:783-798`「那个小混混为什么是恶，因为你说他爹是这个县城的
  一个什么当官的，所以他在这个县城里，**他是凌驾于社会规则之上的**」

**为什么这条重要**：把结构性问题归因于自身，是本主题中**最常见也最有害**的误判——
它会让用户不断"提升自己"去应对一个根本不因自己改变而消失的威胁。

**行动**：识别为"非个人可解"后，不再给自我提升类建议，转入 B17。

## B17 · 下药 / 暴力 / 猥亵属刑事事件，不是情感问题
